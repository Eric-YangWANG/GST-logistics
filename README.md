## 📖 项目简介

**GST（Granularity Shift Theory，粒度跳变理论）** 是一个面向物流与供应链领域的**中层理论框架**，旨在回答三个根本问题：

- 物流效率的**杠杆点**究竟在哪？
- 供应链的**价值**是如何集聚的？
- 上下游之间的**控制权**争夺战怎么打？

GST 不是书斋里的学术产物，而是来自作者近二十年的行业观察、数百轮与 AI 的高强度对话，以及对中国物流产业现场的深度思考。它遵循 **“工程思维，够用就好”** 的原则，基于 **五条公设** 构建，为从业者提供了一套**统一的描述语言**和**可操作的分析工具**。

这套理论不会改变物流行业“搬货”的事实，但它希望改变这个行业思考自己的方式。
